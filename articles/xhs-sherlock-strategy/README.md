# 夏洛克 XHS 运营策略

## 核心结论

大号不做“AI 导师”，也不做泛工具搬运。

最稳的账号方向是：

> 我是老登，不会写代码，但我能用 AI 把工具、数据、网页、流程真正做出来。  
> 我能做的，你也能。AI 时代不用焦虑，跟着我一起实操。

策略关键词：

- 主定位：零代码 AI 实战
- 核心栏目：AI 讲解公司、AI 数据链雷达、Skills / AI 功能实操
- 流量池：X / Ins 骑行热点搬运
- 口吻：真实、实操、不焦虑、不装导师
- 目标：让用户因为“可复制”而收藏，因为“真实跑过”而关注

### 内容判断

1. 骑行不是要砍掉，而是继续作为流量池。
2. DRAM / 海力士不是普通科技商业拆解，要升级为 AI 数据追踪。
3. Circle 是“AI 讲解公司系列”的原型，收藏率高，值得复制。
4. 最新 Skills / AI 功能实操是新增主栏目，适合建立长期关注理由。
5. “不焦虑”只是口吻，不是内容本体；每篇必须有动作、有结果、有模板。

## 账号定位

### 一句话定位

不会写代码的老登，把 AI 跑成普通人能复用的流程。

### 用户为什么关注

- 想用 AI，但不知道从哪里开始。
- 看了很多工具新闻，但没人告诉他怎么落地。
- 不会写代码，又怕 AI 时代被淘汰。
- 需要现成流程、模板、案例，而不是空泛鸡汤。
- 想看一个真实用户怎么踩坑、怎么跑通、怎么复用。

### 不要采用的定位

- AI 导师
- AI 课程号
- 泛工具搬运号
- 投资观点号
- 纯情绪陪伴号
- 财富密码号

### 1. AI 讲解公司系列

来源样本：Circle 互动讲解。

栏目定义：

- 用 AI 把一家公司、商业模式、行业概念讲成人话。
- 不追求研报式完整，追求“普通人终于看懂”。
- 每篇必须有一张图、一个类比、一个你的判断。

可做选题：

- Circle 到底怎么赚钱？
- 为什么稳定币公司会这么值钱？
- 一家公司能不能用 AI 5 分钟看懂？
- AI 给我做了一份公司互动讲解，我发现了什么？

### 2. AI 数据链雷达

来源样本：DRAM / 海力士。

栏目定义：

- 用 AI 做数据追踪，建立热门数据链。
- 不是泛泛点评公司，而是追踪数据、异动和链路。
- 适合 DRAM、HBM、AI 存储、海关、财报、价格、算力、光模块。

标准链路：

```text
数据源 -> 异动检测 -> 公司映射 -> 利润/估值影响 -> XHS 图文解释
```

可做选题：

- DRAM 涨了，为什么海力士 / 美光 / 三星反应不同？
- 韩国海关数据里，哪个口径先反映 AI 存储需求？
- HBM 订单、NAND 价格、服务器需求如何互相验证？
- AI 硬件热点雷达：今天哪条数据值得看？
- 数据链日报：内存、存储、算力、光模块各看一个指标。

### 3. Skills / AI 功能实操

来源样本：Claude / Futu / Gemini / Circle 等工具实操。

栏目定义：

- 看到新的 AI 能力、skills、agent、工作流，自己先跑一遍。
- 不发工具新闻，只发真实跑通后的流程。
- 必须展示输入、过程、输出、卡点、可复用模板。

可做选题：

- 我让 Claude Code 跑了一套 XHS 运营流程。
- 新 skills 到底能不能帮普通人做内容？
- 不写代码，我用 AI 做了一个数据追踪网页。
- 一个 AI agent 从选题到发文能做到哪一步？

### 4. 老登零代码实验

栏目定义：

- 不会写代码也能做一个真实东西。
- 成品可以是网页、看板、自动化、表格图、图文包。
- 重点是“我做出来了，你也可以照着做”。

发文标准：

- 有成品截图。
- 有普通人复现步骤。
- 有踩坑记录。
- 有可复制 prompt 或 checklist。

### 5. X / Ins 骑行热点搬运

栏目定义：

- 继续搬运骑行、F1、运动热点视频，作为流量和人设入口。
- 这类内容过去贡献过 8 万级曝光，不能简单砍掉。
- 但必须加中文解释和你的观点，避免纯搬运。

发文标准：

- 选视频必须有强视觉或强争议。
- 标题要有故事或问题。
- 文案要解释“为什么值得看”。
- 最后可以自然引回“我用 AI / 数据 / 工具看懂它”。

### 6. 可复制流程卡

栏目定义：

- 把工具、数据链、AI 工作流沉淀成 prompt、清单、模板。
- 每篇最后给用户一个可以直接拿走的东西。

适合沉淀：

- prompt
- checklist
- 工具链
- 数据源列表
- 发布模板
- 复盘表

## 大号与小号分工

### 大号：判断和作品

大号负责建立信任和代表作。

主发内容：

- AI 讲解公司系列
- AI 数据链雷达
- Skills / AI 功能实操
- 老登零代码实验
- 少量 X / Ins 骑行热点

大号标准：

- 有观点。
- 有成品。
- 有过程。
- 有判断。
- 有可复制价值。

### 小号：试跑和互动

小号负责试错、互动和素材池。

主发内容：

- 每日 AI 试跑
- 评论区需求实测
- 失败记录
- 工具卡点
- 模板拆解
- 热点话题测试

小号标准：

- 轻一点。
- 快一点。
- 多测试。
- 多问用户要什么。
- 能沉淀的再回流到大号。

## 发文模板

### AI 实操类

```text
标题：我不会写代码，但用 AI 跑通了一个 ___

正文结构：
1. 我想解决什么问题
2. 我用了什么工具
3. 中间卡在哪里
4. 最后做出了什么
5. 普通人怎么复用

结尾：
想要 ___ 模板的，可以评论区说，我整理下一版。
```

### AI 数据链类

```text
标题：___ 涨了，真正该看的不是股价，而是这条数据链

正文结构：
1. 今天发生了什么异动
2. 我用 AI 追了哪几个数据源
3. 数据之间怎么互相验证
4. 映射到哪些公司/行业
5. 下一步继续盯什么

结尾：
这类数据链我准备持续更新，想看哪个行业可以留言。
```

### AI 讲解公司类

```text
标题：一直看不懂 ___？我让 AI 给我讲成人话

正文结构：
1. 这家公司一句话做什么
2. 它怎么赚钱
3. 为什么现在火
4. 最大的问题是什么
5. 我的判断

结尾：
下一个想看哪家公司？评论区丢名字。
```

## 执行边界

### 继续做

- AI 数据追踪和热门数据链。
- Circle 式“讲懂公司/概念”。
- 最新 Skills / AI 功能实操。
- X / Ins 骑行热点搬运，加中文观点。
- 零代码成品、流程卡、模板。

### 控制做

- 纯情绪“AI 不焦虑”，没有动作不发。
- 纯工具新闻，不实测不发。
- 纯投资观点，不接入数据链不发。
- 生活随手发，不强化人设就转小号。
- 导师、课程、财富密码口吻都避开。

## 最终判断

夏洛克大号不是要从零重做，而是要把过去有效的内容重新组织成栏目。

最重要的不是“做 AI 内容”，而是做：

> 一个真实用户用 AI 解决真实问题的连续记录。

下一阶段的胜负手：

1. 把 Circle 做成“AI 讲解公司系列”。
2. 把 DRAM / 海力士做成“AI 数据链雷达”。
3. 把最新 skills / AI 功能做成“真实跑通过程”。
4. 把骑行搬运保留为流量入口，但不让它定义账号。
5. 每篇都留下一个可复制的模板、清单或流程。
