如何观测中国 NAND：一个散户能跑通的数据源决策路径

起点是问题（怎么月度、可持续、散户可得地观测中国 NAND？），答案是外部代理。

路径 A：找国内数据。中国海关 HS6 公开但混合口径；HS8 月度年费 5-30 万；工信部 / 统计局只到大类；长江/YMTC 未上市；A 股相关公司季报不拆 ASP；CFM / TrendForce 中文摘要滞后；终端零售 SSD 价 ≠ NAND 颗粒价。结论：散户能跑通月度的只有混合口径 HS6 ——和韩国 HS6 一样残缺。

路径 B：绕到韩国。Samsung + SK Hynix 合计 49% 全球供给端；TRASS 英文站免 key 可拉；月度滞后 0.5 个月；HS10 间接源（MoneyRecipe）可补；DRAM / MCP 子目可拆，支持减法挖 NAND；目的地拆分中国方向价差可看；2023.01 至今连续。

最终结论：穿透中国 NAND，反而要绕道韩国。
